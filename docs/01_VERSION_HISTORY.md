# S.T.A.크래프트 버전별 의사결정 이력

이 문서는 “무엇을 왜 바꿨는가”를 보존합니다. 과거 버전은 참고자료이며 현재 기준은 v5.0입니다.

## v1.0 — 4050 AI·SW 동료학습 플랫폼

### 핵심 아이디어
- 4050 경력자가 체면과 두려움 없이 AI를 배울 수 있는 동료학습
- 1:1 PT와 4주 과정
- StarCraft의 Tech-tree 은유
- 결과물 중심 Portfolio
- Learner → Builder → Instructor/Architect 확장

### 당시 포함했던 요소
- 4주 Architect Clan Ladder
- 1:1 Fast Tech-tree Day-PT
- Alumni Membership
- 강사 생태계
- Template Marketplace
- YouTube 콘텐츠 유입

### 문제점
- 고객범위가 지나치게 넓었음
- 교육·커뮤니티·컨설팅·Marketplace를 동시에 설명
- 실제 검증 전 3개년 매출과 Marketplace를 크게 제시
- 무엇보다 실제로 하지 않은 Pilot 성과가 섞여 있었음

### 폐기/수정
- “5명 Pilot”, 정량 성과 사례를 FACT에서 완전 제외
- Marketplace는 장기 가설로 후퇴
- 현재 단계는 Pre-validation으로 재정의

## v2.0 — 고객검증 우선 모델

### 변화
- “4050 AI 교육” 자체보다 “업무에 AI를 적용하기 어려운 경력자” 문제로 이동
- 무료/저가 접점과 유료 핵심과정 분리
- 현재 사실과 목표 숫자 구분 시작
- 4050 AI Cafe를 별도 Top-of-Funnel로 보기 시작

### 핵심 학습
- 공공·민간 AI 교육이 이미 많아 단순 AI 교육은 차별성이 약함
- 고객의 문제는 AI 접근보다 활용/업무적용 Gap일 가능성이 큼
- 사용자에게 결과물을 남겨야 하지만, 결과물만 만들면 컨설팅처럼 보일 위험이 있음

## v3.0 — AI Workflow Transformation Sprint

### 핵심 정의
경력자가 실제 반복업무를 4주 동안 Human × AI Workflow로 변환하는 프로젝트 기반 교육.

### 구조
- Week 0 Diagnosis
- Week 1 Discover
- Week 2 Build
- Week 3 Improve
- Week 4 Transform
- Automation Asset: 작동 Workflow + Before/After + Manual + Portfolio
- Do It With You
- Peer Learning
- Cafe → Diagnosis → 1:1 → Sprint → B2B

### 추가된 사업 규율
- 초기 고객가설 축소
- 유료검증 Target
- Completion, Self-edit, 30-Day Usage 등 KPI
- 안전원칙: Human Approval, Data Minimization, Sensitive Data Check
- Problem Library × Solution Library × Human Network

### 남은 문제
- 실제 Asset을 강조할수록 “교육인가, 구축서비스인가?”라는 질문이 남음

## v4.0 — AC/VC 관점의 90점 목표 강화안

### 변화
- Beachhead를 30~300인 조직의 45~59세 팀장/기획/관리자 등으로 더 좁힘
- Human × AI Workflow Transformation Service 표현 강화
- B2B, Unit Economics, Coach Capacity, Workflow Reuse Rate 강조
- Problem/Solution Schema와 보안·운영 논리 강화

### 얻은 것
- 고객 세분화 규율
- B2B 확장논리
- 반복가능성·Unit Economics 관점
- 데이터 자산화 개념

### 사용자 피드백
“교육에서 약한 수준의 컨설팅회사로 변경되는 것 같다.”

### 결과
v4의 사업 규율은 보존하되 정체성은 폐기/수정. S.T.A.의 중심은 “Workflow를 대신 만들어주는 것”이 아니라 “Architect를 양성하는 것”으로 복귀.

## v5.0 — S.T.A. Architect Lab

### 현재 기준

포지셔닝:
S.T.A.크래프트는 AI 자동화를 대신 구축하는 회사가 아니라, 경력자가 자신의 업무를 AI와 함께 다시 설계할 수 있는 AI Workflow Architect로 성장하는 프로젝트 기반 동료학습 서비스다.

### 교육의 두 결과
1. Performance Output — 작동하는 Workflow/Portfolio
2. Learning Outcome — 다른 문제에도 전이 가능한 Workflow Architect 역량

### 학습원칙
- Learner가 항상 Actor
- Expert는 Facilitator / Learning Architect / Coach
- 실제 업무가 교재
- 실제 업무를 못 가져오면 Synthetic Case
- 정답을 먼저 보여주지 않음
- Build → Test → Fix → Modify → Transfer
- Peer Review와 Failure Sandbox를 핵심에 배치

### 상품체계
- 4050 AI Cafe — Discover
- 2-Day Workflow Bootcamp — 14h 집중체험
- Architect Lab 20 — 4주 20h, Workflow Builder
- Architect Lab 40 — 4주 40h, Workflow Architect
- Advanced Lab / Alumni Guild / Facilitator — 추후
- Corporate Architect Lab — 기업 임직원의 직접 설계역량 교육

### Sandbox MVP
Seed Case 6개:
1. 영업실적 주간보고
2. 회의 후속업무
3. 고객문의 분류
4. 직원 VOC 분석
5. 시장정보 Briefing
6. 교육 만족도 분석

### Go-to-Market
4050 AI Cafe → 무료 Sandbox Challenge → 2-Day → 4주 Lab → Portfolio Demo → 콘텐츠 → 다음 고객

레거시 언론사 공동주관은 초기 Acquisition Engine이 아니라 신뢰·B2B 확장 단계의 확성기로 사용. YouTube 광고는 사례 콘텐츠와 Funnel이 검증된 뒤 소액 CAC 실험으로 시작.
