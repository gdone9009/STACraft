# S.T.A.크래프트 Marketing & Go-to-Market

## 1. 마케팅 원칙

초기 S.T.A.의 핵심은 광고비를 많이 쓰는 것이 아니라 “누가 어떤 문제 때문에 돈을 내는가”를 찾는 것이다.

따라서 순서는:
검증 → 증명 → 확장

레거시 언론사는 엔진이 아니라 확성기.
YouTube 광고는 엔진이 아니라 가속기.
초기 엔진은 실제 Case와 학습 결과물이다.

## 2. Core Message

피해야 할 메시지:
- 4050도 AI 할 수 있습니다
- ChatGPT 쉽게 배우기
- 4주 만에 AI 전문가
- 코딩 몰라도 자동화

권장 메시지:
- AI 사용법이 아니라, 내 업무를 다시 설계합니다.
- 당신의 20년 경력을 AI Workflow로 바꿔보세요.
- 매주 반복하는 보고업무 하나를 가져오세요.
- 배우고 끝나는 것이 아니라 직접 설계하고 수정합니다.

연령은 배려의 언어가 아니라 고객맥락이다. 경력자는 디지털 초보로 취급하지 않는다.

## 3. Funnel

4050 AI Cafe
→ 무료 Workflow Challenge
→ 2-Day Workflow Bootcamp
→ Architect Lab 20 / 40
→ Portfolio Demo
→ YouTube/Blog Case Content
→ 신규 고객
→ B2B / 협회 / 기업
→ Corporate Architect Lab
→ 새로운 Problem Case

## 4. 4050 AI Cafe 역할

Cafe는 S.T.A.와 다른 브랜드/접점으로 유지할 수 있다.

Cafe:
- Discover & Learn
- 무료/저가
- 5~30분
- 따라하기
- AI 첫 성공
- Q&A/커뮤니티
- “먼저 쓴 또래”

S.T.A.:
- Build & Transform
- 유료
- 실제 업무/Case
- 다주 과정
- Workflow Asset + Architect 역량

Cafe에서 측정할 Funnel:
Visit → Signup → First Practice → Second Practice → Q&A → Challenge → S.T.A. Diagnosis → Paid

## 5. Free Workflow Challenge

광고 랜딩에서 바로 결제를 강요하지 않는다.

예시 Hook:
“엑셀로 매주 3시간 걸리는 보고업무, AI Workflow로 바꿀 수 있을까요?”

Challenge 구성:
1. Synthetic Case 공개
2. 10분 문제이해
3. 간단 Workflow Canvas
4. 자동 점수가 아니라 질문 기반 Self-check
5. 2-Day 또는 Lab 설명

검증할 것:
- 어떤 직무가 가장 많이 참여하는가
- 어느 Case에서 Completion이 높은가
- 어느 메시지가 Paid Intent로 연결되는가

## 6. YouTube Strategy

초기에는 광고보다 Proof Content가 우선이다.

권장 콘텐츠 구조:
1. BEFORE WORKFLOW
2. 문제분해
3. Learner Design
4. Build
5. Break
6. Fix
7. After / Portfolio

콘텐츠 제목 예시:
- “매주 만드는 영업보고서를 AI Workflow로 다시 설계해봤습니다”
- “AI가 틀렸을 때 멈추는 Workflow는 어떻게 만들까?”
- “자동화보다 중요한 Human Approval Point”
- “50대 팀장의 20년 경험을 Rule로 바꾸는 방법”

실제 학습자 사례를 사용할 때는 동의·익명화·과장금지 원칙을 적용한다.

## 7. YouTube Paid Ads

실제 Funnel이 확인된 뒤 소액 실험.

Creative Test 예시:
A. 생산성형 — “매주 반복하는 보고업무 하나를 가져오세요.”
B. 경력전환형 — “20년 경력을 AI Workflow로 바꾸는 4주.”
C. 차별화형 — “ChatGPT 사용법이 아니라 내 업무를 다시 설계합니다.”

Paid Landing Goal:
광고 → 무료 Challenge 또는 설명회
광고 → 즉시 고가 결제는 초기에는 우선하지 않는다.

측정:
- CTR
- Landing → Challenge
- Challenge Completion
- Challenge → Paid Intent
- Paid CAC
- Cohort Contribution Margin

## 8. 레거시 언론사 공동주관

사용 시점:
- 초기 PMF 이전의 대규모 모집수단보다는
- 신뢰확보
- B2B 접근
- Conference
- 직무전환/AI업무혁신 담론 확산
단계에서 사용

추천 형식:
“Human × AI Workflow Transformation Conference”
오전: 공개세미나
오후: S.T.A. Workflow Challenge

역할:
언론사 — Media / Reach / Trust
S.T.A. — Curriculum / Sandbox / Facilitator / Education IP

주의:
공동주관 때문에 평범한 “생성형 AI 활용 특강”으로 변질시키지 않는다.

## 9. 협회·기관 파트너

언론사보다 먼저 실험할 수 있는 파트너:
- HR 관련 협회 → HR Case
- 영업/마케팅 단체 → Sales Case
- 창업기관 → Founder Workflow
- 평생교육기관 → Career Transition
- 기업 HR/L&D → Corporate Architect Lab

파트너가 가진 Domain Problem을 Synthetic Case로 일반화할 수 있다면 교육 Content Flywheel이 강화된다.

## 10. B2B Message

하지 말아야 할 표현:
“귀사의 업무를 자동화해드립니다.”

권장:
“귀사의 실무자가 자기 업무를 직접 AI Workflow로 설계하고 개선할 수 있도록 프로젝트 기반으로 훈련합니다.”

기업이 얻는 것:
- 학습자의 Capability
- Workflow Asset
- 사내 Case Library 가능성
- Human Approval/Safety 습관

## 11. 초기 3단계 실행

### Stage 1 — Validate
- 30명 인터뷰
- Free Challenge
- 2-Day 유료 소규모 모집
- 광고비 최소

### Stage 2 — Prove
- Portfolio Demo
- 20h/40h 첫 Cohort
- 사례 콘텐츠
- 소액 YouTube 광고 실험

### Stage 3 — Expand
- B2B
- 협회
- 언론사 공동 Event
- 광고 확장

## 12. 현재 금지사항

현재 실제 유료 Pilot이 없으므로 다음을 마케팅 문구로 사용하지 않는다.
- “검증된”
- “수강생 90%”
- “업무시간 80% 절감”
- “재구매율”
- “누적 고객”
- 실제로 존재하지 않는 후기/기업로고

Prototype에는 Sample/가상 Case임을 명확히 표시한다.
